# baja_3w_autodesign
Electric Vehicle System Design — Bajaj Auto Limited: Proposed and designed a prototype for a 3-wheeler Electric
Autorickshaw in collaboration with Bajaj Auto Limited, targeting urban last-mile mobility. Engineered a fast-charging
architecture to reduce downtime, optimising battery management for extended cycle life and improved energy efficiency.
Integrated a Tyre Pressure Monitoring System (TPMS) and next-generation features to enhance vehicle safety, reliability, and
driver experience.
